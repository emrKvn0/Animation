# Cosmic Dust Studio v4.0

Interactive WebGL / GLSL shader art studio and animation generator built with Three.js, vanilla JavaScript, and custom fragment/vertex shaders.

🔗 **Live Preview (GitHub Pages):** https://emrkvn0.github.io/Animation/

## Features

- **Shader Designer Suite:** Real-time GLSL cosmic dust & procedural noise engine with customizable speed, scale, complexity, detail, and color palettes.
- **Interactive Brush & Zoom:** Hold `ALT` to paint directly onto the shader canvas and `Z` to zoom.
- **Multi-Aspect Canvas:** Switch between 9:16 Story (Portrait), 16:9 Cinema, 1:1 Square, and high-resolution render presets (up to 4K/8K 60FPS).
- **Project Vault:** Create, duplicate, export, and import studio presets locally.

## Run Locally

No build step required. Open `index.html` with any static server (e.g. VS Code Live Server or `npx serve .`):

```bash
npx serve .
```
